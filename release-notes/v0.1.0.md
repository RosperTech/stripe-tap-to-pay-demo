# Rosper Tap to Pay 0.1.0 — Evaluation preview

Evaluate local device conditions for Stripe Tap to Pay on SUNMI Android devices and demonstrate the configured payment flow with Stripe's simulated reader.

**Download `Rosper-Tap-to-Pay-0.1.0-release.apk` from Assets below.** The app is named **Rosper Pay** after installation. GitHub's Source code archives contain the distribution documentation, not application source.

[English guide](https://github.com/RosperTech/stripe-tap-to-pay-demo/blob/main/README.md) · [中文安装说明](https://github.com/RosperTech/stripe-tap-to-pay-demo/blob/main/README.zh-CN.md) · [Device testing guide](https://github.com/RosperTech/stripe-tap-to-pay-demo/blob/main/docs/TESTING.md)

## Before demonstrating

- No backend address, payment key or Terminal Location is included. Local checks are available after installation; payment demos require an operator-provided test backend.
- **Demo mode defaults to OFF.** For a simulated demo, use a Stripe test-mode backend, enable **Use a simulated card reader** before saving settings and confirm **SIMULATED** in the app.
- No SUNMI device, physical card payment, capture or refund was independently tested for this release. A simulated success is not evidence of NFC/payment compatibility; a non-simulated reader connection and any payment tests must be recorded separately.
