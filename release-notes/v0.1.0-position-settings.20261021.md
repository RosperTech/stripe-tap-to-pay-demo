## 中文

这次更新预置了服务器、设备访问凭据和门店配置，新安装无需手动填写这些项目。新增拍卡提示位置设置，可选择设备默认位置、调整自定义位置并恢复默认。

维护方确认预置后台仅用于 Stripe 测试环境。本 APK 用于设备评估和演示。

**免手动配置不等于所有设备都能拍卡收款。** App 仍会检查设备条件；真实读卡器连接和支付流程需要在符合条件的设备上验证。Demo mode 默认关闭，模拟读卡器开关不会切换后台的 Stripe 测试/正式环境。

### 下载与安装

1. 点击上方“下载 APK”，或在本页 Assets 中下载 `Rosper-Pay-5.8.1-position-settings.apk`。
2. 按 Android 提示允许安装，打开 **Rosper Pay** 并授予使用期间的定位权限。
3. 开启设备 NFC、网络和定位服务，关闭开发者选项；查看设备检查结果。
4. 如需调整拍卡提示位置，在 **Settings** 中选择自定义位置并保存；也可恢复设备默认位置。

**旧版升级：本 APK 与原 `v0.1.0` 的签名不同，不能直接覆盖安装。** 建议使用没有旧版的新测试设备。若使用原设备，先处理未完成交易并保存所需记录，再卸载旧版后安装；卸载会删除本地设置与数据。

## English

The APK includes preset backend, device credential and Terminal Location values. A fresh installation does not require manual entry of those settings. Tap-position settings now support device defaults, a custom position and reset to defaults.

The maintainer confirms that the preset backend is for Stripe testing only. This APK is for device evaluation and demonstrations.

Fresh installation and startup were verified on a Samsung SM-T733 running Android 14 on 2026-10-23. A custom position of 30% horizontal / 70% vertical survived a cold restart; restoring the default also survived a restart. This tablet has no NFC and failed additional local checks. No reader connection or payment, capture or refund was tested. SUNMI CPAD remains untested.

**The signing certificate differs from the original `v0.1.0` APK; an in-place upgrade is not supported.** Prefer a fresh test device. Before uninstalling the old APK, resolve pending transactions and preserve needed records; uninstalling removes local data and settings.

Demo mode defaults to OFF. Selecting a simulated reader does not change the backend's Stripe test/live mode. Preset configuration does not establish device compatibility or successful payment processing.
